Clickjacking (UI Redressing)

An attacker overlays an invisible, actionable interface over an authentic button to hijack user interactions without consent.

SECTION 01

What it is

Clickjacking (OWASP A05:2021 • CWE-1021) overlays an invisible, clickable layer over a visible button. Visitors think they are clicking a harmless prize, but their click triggers an underlying action. Missing framing headers allow malicious pages to frame the site.

SECTION 02

Vulnerable action endpoint missing framing headers:

3  <h3>One-Click Account Transfer</h3>
4  <p>Recipient: attacker@evil.test</p>
5  <button id="confirmBtn" onclick="executeTransfer()">Confirm Action</button>
6</div>

8  // Missing frame-busting check allows embedding

10</script>
Highlighted Line 5: Triggers on clicks without validating if framed by an attacker.
sensitive-action.html (Hardened) DEFENSE ENFORCED 
1<!-- Modern Server Defense: CSP frame-ancestors 'none' -->
2<script>
3  if (window.top !== window.self) {
4    window.top.location = window.self.location; // Frame-busting guard
5    document.body.style.display = "none";       // Deny rendering in frames
6  }
7  function executeTransfer() {
8    if (window.top !== window.self) throw new Error("Framing prohibited");
9    finalizeTransaction(500);
10  }
11</script>
Highlighted Lines 3–5: Frame-buster confirms top-level context, denying nested iframe clicks.
SECTION 04

Why it matters

Clickjacking tricks authenticated visitors into unintended transfers, deletions, or permission grants without consent.

Real-World Incident: In 2009, Twitter's viral "Don't Click" worm used transparent button overlays to force users to unknowingly retweet the exploit upon clicking anywhere on the page.

Clickjacking

CWE-1021 OWASP A05:2021 — Security Misconfiguration
← Back to Labs Next: Open Redirect →

1 What It Is

Clickjacking (also called "UI redressing") tricks a user into clicking something different from what they see. The attacker loads a legitimate page inside a transparent <iframe> and places an enticing decoy over it. When the victim clicks the decoy, the click actually hits the hidden page — triggering actions like deleting an account or transferring funds.

2 The Vulnerable Code

The target page has no frame-busting protection, so any site can embed it.

attacker-page.html 
<style>
  iframe {
    position: absolute;
    opacity: 0.0001;   /* ← invisible but clickable */
    width: 100%; height: 100%;
    z-index: 10;
  }
</style>

<!-- Bait the user sees -->
<button>🎉 Claim Your Prize!</button>

<!-- Hidden victim page -->
<iframe src="https://bank.com/settings"></iframe>

Why it's dangerous: The opacity: 0.0001 makes the iframe invisible while keeping it interactive. The iframe loads the real banking page on top of the bait button. Because the target page sends no X-Frame-Options header, the browser allows this.

4 Why It Matters

Clickjacking lets attackers make users perform actions they never intended: liking a page, enabling a webcam, transferring money, or changing account settings. The victim has no idea — the page looks normal to them.

Real incident: In 2008, researchers Jeremiah Grossman and Robert Hansen demonstrated clickjacking attacks that could enable a user's webcam and microphone through Adobe Flash without any permission dialog — just by clicking a seemingly innocent button. Adobe had to issue an emergency patch.

5 The Fix

Add HTTP response headers that tell browsers to refuse framing your page.

server-response-headers.conf 
# Apache / Nginx — add these response headers

X-Frame-Options: DENY

Content-Security-Policy: frame-ancestors 'none'

# The browser now refuses to render this page
# inside any <iframe>, <frame>, or <object>.

# Optional: JavaScript frame-buster (defense in depth)
if (window.top !== window.self) {
  window.top.location = window.self.location;
}

Why it works: X-Frame-Options: DENY tells the browser to never render this page in a frame. frame-ancestors 'none' is the modern CSP equivalent. Together they make the transparent-iframe attack impossible — there's nothing to click on.
