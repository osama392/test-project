OWASP A01:2021 — Broken Access Control CWE-601 Interactive Lab 02

Open URL Redirection

An unvalidated redirect parameter tricks users into trusting a link originating from a legitimate site that silently hands them over to an attacker.

Sandbox Defense Controller

● Vulnerable Mode Active — Unchecked target redirection

SECTION 01

What it is

Open Redirection (OWASP A01:2021 • CWE-601) occurs when an application accepts untrusted input via parameters like ?next= and redirects visitors without destination validation. Phishing attacks exploit this because the initial link points to a trusted domain, deceiving victims and bypassing email security filters.

SECTION 02

The line

Vulnerable script extracting query parameter directly into location:

redirect-handler.js (Vulnerable) VULNERABLE 
1function handleLoginSuccess() {
2  const params = new URLSearchParams(window.location.search);
3  const targetUrl = params.get("next");
4  
5  if (targetUrl) {
6    window.location.href = targetUrl; // Blind redirection to attacker site
7  } else {
8    window.location.href = "/dashboard";
9  }
10}
Highlighted Lines 5–6: Forwards the browser to targetUrl without destination origin validation.
redirect-handler.js (Hardened) ALLOW-LIST ENFORCED 
1function isSafeRedirect(url) {
2  // Enforce relative paths only; reject absolute protocols and // bypasses
3  return /^\/(?!\/)[a-zA-Z0-9_\-\/]+$/.test(url);
4}
5function handleLoginSuccess() {
6  const target = new URLSearchParams(window.location.search).get("next");
7  if (target && isSafeRedirect(target)) {
8    window.location.href = target;
9  } else {

Highlighted Lines 2–3 & 7: Strict allow-list regex enforces single-slash relative paths, rejecting external targets.
SECTION 04

Why it matters

Open redirects turn reputable domains into attack vectors for credential theft. Users assume links on trusted domains are safe, landing on credential harvesting forms.

Real-World Incident: In 2021, cybercriminals exploited unvalidated redirects on American Express and Snapchat landing pages to orchestrate widespread Microsoft 365 credential harvesting attacks.
